This is a fairly new project. It’s worth noting that it requires a somewhat advanced level of knowledge, as the connections are modeled very precisely after a breadboard. There is a vast array of components available, all of which are fully functional!

<img width="1035" height="794" alt="Captura" src="https://github.com/user-attachments/assets/b585bfdc-48f7-4ad6-9ca2-1c8b51426ad1" />


The tool includes features for circuit analysis and patching—essentially simulating a DAW, but with a breadboard-style interface (much like a Eurorack system). It also features knobs that you can tweak to perform and explore a wide range of sounds. To get you started, it comes with two built-in sounds: a kick drum preset for building rhythms, and a synth patch for you to experiment with.

<img width="1481" height="772" alt="Captura 2" src="https://github.com/user-attachments/assets/4821c44b-5897-44a6-ae04-2c92be0b864e" />

The project was compiled using C++ and runs via Neutralino. You should launch it by opening the `.bat` file—that’s the main entry point! Alternatively, you can open the Neutralino executable directly; both methods work, but using the `.bat` file is the recommended way.

Good luck! For those not using Windows, I’ve also provided a web-based version, so you can share projects and enjoy the experience without any limitations. (It even works on mobile phones!)
